02. 배경 이미지
배경 이미지 추가
위의 파일 선택 버튼을 직접 눌러 이미지를 고르세요. 선택할 때마다 기존 목록 뒤에 계속 추가됩니다.
선택된 이미지 없음
선택한 이미지를 편집창에 고정해서 보여주는 중입니다. 미리보기에서 배경을 드래그하면 위치가 바뀌고, 마우스 휠로 20%~300%까지 확대/축소할 수 있습니다.
100% 아래로 내리면 이미지 전체를 더 작게 배치할 수 있습니다.
이미지 이름을 누르면 그 이미지가 재생 순서와 상관없이 편집창에 바로 뜹니다. 각 이미지마다 크레딧의 좌우 위치, 글자 정렬, 배경 흐림이 따로 저장됩니다. 재생 버튼을 누르면 다시 실제 타임라인으로 돌아갑니다.

05. 음악
음악 파일 추가
선택된 음악 없음
음악이 짧으면 반복
마지막 화면에서 페이드아웃
음악은 영상 시작과 함께 재생됩니다. 곡 시작 지점으로 노래의 어느 부분부터 쓸지 정할 수 있습니다. GIF에는 소리를 넣을 수 없지만 MP4/WebM 영상에는 음악이 함께 저장됩니다.
06. 저장
GIF와 영상 길이는 이미지별 표시 시간의 합 + 마지막 화면 유지 시간을 자동으로 사용합니다. GIF는 무음이며, 영상은 음악이 있으면 함께 저장합니다. MP4를 우선 시도하고 지원되지 않으면 WebM으로 저장합니다.
